# VRC Cache Mover

VRChat（PC 版）の **キャッシュ** と **カメラ写真** の保存先を、画面上の操作だけで別のドライブへ変更するツールです。

VRChat 公式の設定ファイル `config.json` を書き換えるだけで、VRChat 本体の改造や、ジャンクション／シンボリックリンクの作成は一切行いません。

- 公式ドキュメント（英語）: https://docs.vrchat.com/docs/configuration-file

このツールは公式の手順を自動化したもので、仕組みはシンプルです。手作業でも同じことができるので、中身を確認したい方や手で設定したい方は、上の公式ドキュメントの `cache_directory` と `picture_output_folder` の項目をご覧ください。

## 保存先を移すメリット

### キャッシュ
- **C: ドライブの空きが最大約 30GB 増えます。** VRChat のキャッシュは既定で C: に最大 30GB まで溜まります（作者の環境では約 31GB ありました）。移動後は C: に溜まらなくなり、元の場所の古いキャッシュを「古いキャッシュを削除...」で消すと、その分の空きが戻ります。
- **C:（システムドライブ）への書き込みが減ります。** キャッシュはワールドやアバターを読み込むたびに書き込まれ、上限に達すると古いものから入れ替わり続けます。この書き込みを別のドライブに逃がせるので、OS の入った SSD の負担を減らせます。
  - 作者の実測（移動は少なめでフレンドと過ごす、まったり気味の遊び方で約 4 時間）では、遊んでいる間の C: への書き込みが**約 2 割減りました**。初めてのワールドを次々に回る遊び方なら、もっと減ります。
  - 移動後、C: へのキャッシュの書き込みはゼロになりました。ログなど、VRChat がキャッシュ以外で C: に書く分は残ります。Windows や他のアプリも C: に書き込むので、C: への書き込みがゼロになるわけではありません。
- **容量の大きいドライブなら、キャッシュの上限を増やせます。** 上限（既定 30GB）を増やすと、一度行ったワールドやアバターが消えにくくなり、再訪時のダウンロード待ちが減ります。
- **C: がいっぱいになったときの不調を避けられます。** システムドライブの空き不足は、Windows の更新失敗や動作の不安定さにつながります。

### 写真
- **撮れば撮るほど増える写真で C: が圧迫されません。** 写真は 1 枚あたり数 MB あり、撮る人ほど気付かないうちに増えていきます（作者の環境では約 1 年半で約 12 GB、よく撮る月は 1 か月で 1.5 GB 前後）。

  | 解像度 | 1 枚あたり | 1,000 枚あたり |
  |---|---|---|
  | 1080p（1920×1080） | 約 2.2 MB | 約 2.2 GB |
  | 1440p（2560×1440） | 約 4.3 MB | 約 4.2 GB |
  | 4K（3840×2160） | 約 8.2 MB | 約 8 GB |

  作者が撮った写真約 3,800 枚（PNG）の実測値（中央値）です。写っている内容によって増減し、背景透過で撮るとやや大きくなります。
- **大容量のドライブにまとめておけるので、バックアップや整理がしやすくなります。**

### おすすめの移動先
- 移動先は**内蔵の SSD（NVMe など）**がおすすめです。VRChat 本体を入れている Steam ライブラリと同じドライブなら、読み込み速度も今までと同等です。
- 内蔵の HDD でも動きますが、キャッシュ済みワールドの読み込みは SSD より遅くなります。
- 写真の保存先を HDD にすると、しばらく撮らなかった後の 1 枚目で、一瞬止まることがあります（作者の環境で発生。HDD が省電力で止まっていて、回転し始めるのを待つためと思われます）。気になる場合は写真も SSD にしてください。
- USB 接続の外付けドライブも、常に接続したままなら使えます。ただし、抜く運用やドライブ文字の変化には注意が必要です（「注意」を参照）。

## こんな人向け

- C: ドライブの空きが少ない（VRChat のキャッシュは既定で約 30GB）
- システムドライブ（C:）への書き込みを減らしたい
- 写真を別のドライブにまとめたい
- `config.json` を手で作るのが不安（拡張子、`\` のエスケープなど）

## 動作環境

- Windows 10 / 11（標準搭載の Windows PowerShell 5.1 で動きます。追加のインストールは不要です）
- PC 版 VRChat（一度は起動したことがある環境）

## 使い方

1. **VRChat を終了します。**
2. `VRCCacheMover.bat` をダブルクリックします。
3. 「キャッシュ」と「カメラ写真」の保存先をそれぞれ指定します。
   - 「参照...」で場所を選ぶと、その中に専用フォルダ（`VRCCache` / `VRChatPhotos`）が自動で付きます（チェックを外すと、選んだフォルダをそのまま使います）。
   - 空欄にすると VRChat の既定の場所に戻ります。
4. 「適用」を押し、確認画面で内容を確かめて「はい」を押します。
5. VRChat を起動します。指定したフォルダにファイルが増えれば成功です。

### 適用後に VRChat が作るフォルダ（作者の環境での実測）

- キャッシュの保存先の中に `Cache-WindowsPlayer` と `TextureDiskCache-WindowsPlayer`
- 写真の保存先の中に `2026-11` のような月ごとのフォルダ（「月ごとのフォルダに分ける」がオンのとき）

## このツールが変更するもの

`%USERPROFILE%\AppData\LocalLow\VRChat\VRChat\config.json` の次の項目だけです。それ以外の項目（カメラ解像度など）はそのまま残します。

| 項目 | 内容 |
|---|---|
| `cache_directory` | キャッシュの保存先 |
| `cache_size` | キャッシュの容量上限（GB、30 以上。30 のときは書きません） |
| `picture_output_folder` | カメラ写真の保存先 |
| `picture_output_split_by_date` | 月ごとのフォルダに分けるか（オンのときは書きません） |

- 書き換える前に、元のファイルを `config.json.bak-日付-時刻` として同じ場所に残します。
- すべて既定に戻して書く項目がなくなった場合は、`config.json` を削除します（バックアップは残ります）。

## 元に戻すには

ツールで各項目の「既定に戻す」を押して適用するか、バックアップの `config.json.bak-…` を `config.json` に名前を戻してください。

戻るのは設定だけです。削除した古いキャッシュは戻りません（必要になれば VRChat が再ダウンロードします）。自分で移した写真は、エクスプローラーで元の場所へ戻してください。

## 注意

- **古いキャッシュは自動では削除しません。** 新しい場所にファイルが増えたのを確認してから、「古いキャッシュを削除...」で削除できます。消すのは `%USERPROFILE%\AppData\LocalLow\VRChat\VRChat` の `Cache-WindowsPlayer` と `TextureDiskCache-WindowsPlayer` だけで、削除前に容量を表示して確認します（ごみ箱には入りませんが、必要になれば再ダウンロードされるだけです）。キャッシュの保存先を移していないとき、VRChat の起動中、フォルダの中にリンクがあるときは削除しません。
- **これまでの写真は移動しません。** 新しく撮った写真から指定先に保存されます。移したい場合は、適用後に「写真フォルダを開く」で元の場所と新しい場所を開き、エクスプローラーで移してください。元の場所が OneDrive の中にあるときは、外へ移すと OneDrive（クラウド）からも消えます（ツールも表示します）。
- **USB 接続の外付けドライブを指定する場合**は、次の点に注意してください（ツールも警告を出します）。
  - ドライブを外した状態や電源を切った状態で VRChat を起動すると、保存先が見つからなくなる可能性があります。
  - 他の USB 機器を挿す順番などで**ドライブ文字が変わる**と（例: `F:` → `G:`）、指定したパスとずれます。その場合はツールで指定し直してください。
- VRChat の起動中は適用できません。
- 写真フォルダをすでにシンボリックリンク等で移動している場合は、ツールが検知して表示します。リンクには触れません。リンク先と別の場所を指定すると、写真が 2 か所に分かれます。
- ログ（`output_log_*.txt`）の保存先は公式に変更できないため、このツールの対象外です。

### 「Windows によって PC が保護されました」と出る場合

インターネットから入手したバッチファイルには、Windows が警告を出すことがあります。「詳細情報」→「実行」で起動できます。中身はテキストファイルなので、メモ帳で開いて何をしているか確認できます。
